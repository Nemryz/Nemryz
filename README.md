**[bot-epub-translater](https://github.com/Nemryz/bot-epub-translater-)** [![In progress](https://img.shields.io/badge/In_progress-33C3F0?style=for-the-badge)](https://github.com/Nemryz/bot-epub-translater-)

**[identity-generator](https://github.com/Nemryz/identity-generator)** [![Stable](https://img.shields.io/badge/Stable-6FCF97?style=for-the-badge)](https://github.com/Nemryz/identity-generator)
A CLI tool for generating coherent synthetic identities with locale-matched personal information, including names, addresses, contact details, and configurable fields. It can also create temporary email accounts through supported providers, with optional inbox access when available, or generate offline placeholder addresses when network access is disabled. The resulting data can be exported to JSON or CSV, making the tool suitable for testing, development, demonstrations, and other environments that require structured fictional identities.
